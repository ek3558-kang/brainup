# 브레인업 (BrainUp) v0.1.0

안드로이드 태블릿용 영어 단어 학습 앱의 **첫 구현 소스**입니다.

## 구현된 기능
- 시작 화면의 큰 월간 학습 달력, 큰 O/X 표시, 월 이동
- 하늘색~파란색 테마 (#258EDB)
- 초등 고학년 단어 60개 내장 (초기 개발용 샘플, 정식 교육과정 검수 전)
- 신규 최대 10개 + 복습 예정 최대 20개 자동 선정
- 직접 입력 퀴즈: 영어 철자 80%, 한국어 뜻 20%
- 연습 중 즉시 피드백, 평가 종료 후 일괄 피드백
- 평가 정답률 80% 이상 시 O 기록
- 사용자 단어 직접 등록/삭제
- 기기 로컬 학습 기록 저장
- 학습 알림 없음

## 설치 및 실행
Flutter SDK 및 Android SDK가 설치된 개발 PC에서:

```bash
flutter create --platforms android .
flutter pub get
flutter run
```

태블릿이 USB 디버깅으로 연결되어 있어야 합니다. APK 생성:

```bash
flutter build apk --release
```

APK는 일반적으로 `build/app/outputs/flutter-apk/app-release.apk`에 생성됩니다.

## 아직 구현되지 않은 기능 (중요)
- **자동 뜻 검색/AI 예문:** 아직 미연결. 현재는 영어 단어와 한국어 뜻을 모두 입력해야 합니다.
- **FSRS:** 아직 미구현. 현재는 정답 여부에 따라 1일 → 3일 → 2배 간격으로 복습하는 간단한 임시 스케줄러입니다.
- 중학교·고등학교 단어 자동 업데이트/승급, 전체 교육과정 어휘 데이터
- 철자 오류 제안, 동의어 정밀 판정, 실제 음성 듣기, 문장 빈칸
- 데이터 내보내기/백업, 계정 동기화, 세부 학습 분석
- APK 빌드 및 실제 기기 테스트: 현재 환경에 Flutter SDK가 없어 수행하지 못했습니다.

## 현재 버전의 운영상 주의사항
- 초기에는 복습 이력이 없으므로 30문제를 채울 수 없습니다. 학습 가능한 단어만 평가하고 그날의 평가 문제 수를 표시합니다.
- 달력은 과거 날짜 중 학습 기록이 없는 날을 X로 표시합니다. 앱 설치 이전 날짜도 X로 보일 수 있으며, 추후 설치 시작일 처리 개선이 필요합니다.
- 같은 날 재평가 시 평가 대상 목록은 앱 실행 중 유지되지만 앱을 재시작하면 재구성됩니다.
- **한국어 뜻 판정은 기본적으로 등록된 뜻과 일치하는지만 확인**하므로 유의어 인식이 제한적입니다.
- 연습 모드는 학습 진도와 복습 스케줄을 변경하지 않습니다.
- 테스트되지 않은 초기 소스이므로 빌드 오류나 사용성 문제가 있을 수 있습니다.

## APK를 자동으로 만드는 방법 (GitHub Actions)
이 소스에는 `.github/workflows/build-apk.yml`이 포함되어 있습니다.
GitHub 저장소의 `main` 브랜치에 이 프로젝트 파일을 올린 뒤, **Actions → Build BrainUp Android APK → Run workflow**를 실행하세요.
빌드가 성공하면 해당 실행의 **Artifacts → brainup-debug-apk**에서 ZIP을 받아 압축을 풀고 `app-debug.apk`를 설치할 수 있습니다.
이 워크플로는 Android 프로젝트를 생성하고 Flutter를 설치한 뒤 디버그 APK를 빌드합니다. 실제 빌드 성공 여부는 GitHub에서 확인해야 합니다.
